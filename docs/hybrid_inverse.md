# Гибридная инверсия: варианты эксперимента

В проекте есть два разных подхода. **Текущая глубокая гибридная CNN** обучает энкодер и морфологическую ветвь совместно; её архитектура и test-результаты описаны в [deep_hybrid_inverse.md](deep_hybrid_inverse.md). **Гауссовская инверсия** использует замороженную исходную CNN и отдельную вероятностную голову — см. [gaussian_inverse.md](gaussian_inverse.md).

Ниже сохранены инструкции для раннего эксперимента с замороженными embedding в `20_hybrid_inverse.ipynb`. Они не описывают обучение глубокой модели из `20_deep_hybrid_inverse.ipynb`.

## Ранний гибрид на замороженных embedding

Открой `notebooks/20_hybrid_inverse.ipynb` и выполняй ячейки сверху вниз.
Новые модули `src/cnn_inverse.py` и `src/hybrid_inverse.py` должны лежать рядом
с существующим кодом в папке `src`.

Требуются локальные результаты предыдущих ноутбуков:

- `data/ml_dataset/dataset_inverse.csv` из ноутбука 17;
- маски `.npz`, указанные в `image_path` относительно `data/ml_dataset`;
- `results/cnn_inverse/best_cnn.pt` из ноутбука 19.

Используй тот же датасет и порядок строк, на котором обучалась CNN.
Старый checkpoint не содержит исходных run_id: ноутбук воспроизводит split
с seed 42 и проверяет train-статистики, но это не заменяет сохранённый манифест.
Новый эксперимент уже сохраняет run_id и SHA-256 входных файлов.

Окружение должно включать PyTorch, scikit-learn, NumPy, pandas, SciPy,
Matplotlib и Jupyter. Новые зависимости добавлены в `requirements.txt`.

CNN полностью заморожена. Извлечение embedding выполняется один раз,
после чего три небольшие головы обучаются на таблицах: 128 признаков CNN,
27 признаков морфологии и их объединение из 155 признаков.
Аугментация отключена, чтобы маска соответствовала готовым признакам.
Масштабы и заполнение пропусков вычисляются только на train.

Результаты появятся в `results/hybrid_inverse`: метрики и предсказания validation,
кривые обучения, график восстановления, preprocessing, манифест и модель
`best_hybrid.pt`. Test автоматически не оценивается.

Для применения сохранённой модели используй
`from src.hybrid_inverse import load_hybrid_checkpoint`.
Вызов `model(masks, morphology)` принимает `[N, 1, 128, 128]` и `[N, 27]`
в порядке `saved['feature_columns']`, возвращает `[N, 4]` в исходных единицах.
Морфологические признаки на входе должны быть исходными, без нормализации.

Проверки: `python -m unittest discover -s tests -v` из корня проекта.

Один запуск не доказывает преимущества гибрида. Сравни его с `embedding_only`,
затем повтори обучение с несколькими seed. Новая голова сама по себе может
изменить качество относительно исходной CNN. На новых моделях не следует
подбирать настройки по уже изученному test.
