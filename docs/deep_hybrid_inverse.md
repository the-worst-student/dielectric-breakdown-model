# Глубокая CNN с морфологией

Ноутбук: `notebooks/20_deep_hybrid_inverse.ipynb`.

Модель принимает бинарную маску 128 × 128 и 27 морфологических признаков. Все **1 793 764 параметра** обучаются совместно с нуля.

| Часть | Реализация |
|---|---|
| Энкодер | Четыре уровня: 16 → 32 → 64 → 128 каналов; по два residual-блока на уровень |
| Residual-блок | Conv 3×3 → BatchNorm → ReLU → Conv 3×3 → BatchNorm; сложение со входом и ReLU |
| Skip connection | Identity при совпадении каналов, проекция Conv 1×1 + BatchNorm при смене каналов |
| Уменьшение размера | MaxPool после каждой пары блоков; итог 128 × 8 × 8 |
| Агрегация | Adaptive average + maximum pooling до 4 × 4; объединение в 4096 значений |
| Ветка изображения | 4096 → 256 → 128; ReLU и dropout 0.25 |
| Ветка морфологии | 27 → 64 → 32; ReLU |
| Общая голова | 160 → 64 → 4; ReLU и dropout 0.20 |

Обучение: стандартизация целей по train, SmoothL1, AdamW, снижение learning rate по validation loss и early stopping. Train / validation / test: 6560 / 1706 / 1933 маски; группы разделены по `point_id`.

| Параметр | Test MAE | Test R² | Изменение относительно исходной CNN |
|---|---:|---:|---|
| η | 0.2271 | 0.8215 | Небольшое улучшение MAE |
| E_bd⁽⁰⁾ | 0.1344 | 0.0638 | Убедительного улучшения нет |
| ℓc | 3.2786 | 0.1707 | Ухудшение MAE |
| k | 2.2677 | 0.4398 | Убедительного улучшения MAE нет |

Парный кластерный бутстрэп: 5000 повторов с перевыборкой 1401 test-точки параметров и сохранением повторных запусков внутри каждой группы. Для MAE(CNN) − MAE(deep hybrid) интервалы составили: η [0.00201, 0.01742], E_bd⁽⁰⁾ [−0.00364, 0.00003], ℓc [−0.17575, −0.03943], k [−0.05083, 0.04105]. Это поточечные 95% интервалы для фиксированных моделей, без поправки на множественные сравнения.

![Сравнение R² на test](images/inverse_test_r2.png)

Увеличение глубины и добавление морфологии не дали общего улучшения восстановления. Гауссовская модель далее использует **исходную CNN**, а не этот глубокий энкодер.
